# Data, model, and dashboard governance

- **Privacy:** identify personal or sensitive data and document minimization, anonymization, retention, and access.
- **Licensing:** record the license and attribution for every external dataset, image, API, and library.
- **Lineage:** connect source data to transformations, notebook outputs, dashboard measures, and the final recommendation.
- **Reproducibility:** record versions, retrieval dates, environment definition, random seeds, and manual steps.
- **Responsible use:** document bias, uncertainty, acceptable use, and decisions the dashboard/model must not make.
