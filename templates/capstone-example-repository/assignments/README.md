# Capstone milestones

| Milestone | Evidence | Review question |
| --- | --- | --- |
| 01 — Problem framing | Project charter and stakeholder map | Is the business decision specific and actionable? |
| 02 — Data contract | Source inventory, data dictionary, quality rules | Can another person judge whether the data is fit for purpose? |
| 03 — Architecture | Context diagram and ADRs | Are alternatives, trade-offs, and operational consequences visible? |
| 04 — Analysis | Reproducible notebook and tested transformations | Can the result be regenerated and challenged? |
| 05 — BI product | KPI catalog, dashboard evidence, usability review | Does the dashboard support a decision for a defined audience? |
| 06 — Delivery | Runbook, CI checks, risk register | What happens when the data, model, or pipeline fails? |
| 07 — Executive review | One-page recommendation and technical appendix | Is uncertainty communicated without hiding important detail? |
